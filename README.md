# FEFU Checker

Лёгкий веб-инструмент для абитуриентов Дальневосточного федерального университета (ДВФУ). Помогает быстро узнать свою позицию в конкурсных списках поступления.

Данные загружаются напрямую с публичного API ДВФУ. Введите код направления и свой код абитуриента — приложение покажет позицию в конкурсе, сумму баллов, приоритет и попадаете ли вы в зону зачисления.

## Возможности

- Поиск абитуриента по коду в конкурсном списке направления
- Абсолютная позиция в списке (`№`)
- Сумма баллов, приоритет направления, признак высшего приоритета (ВПП)
- Индикатор «в зоне зачисления / вне зоны» по квоте секции
- Общая таблица списка с подсветкой вашей строки и кнопкой «Найти меня в таблице»
- Пресеты популярных направлений (09.03.04, 09.03.01, 09.03.03 и др.)
- Фильтры: форма обучения, финансирование, кампания, сортировка, только ВПП
- Сохранение последних введённых данных в `localStorage`
- Состояния интерфейса: загрузка, успех, «не найден», пустой список, ошибка с кнопкой «Повторить»
- Mobile First, один файл, без сборки и тяжёлых зависимостей

## Быстрый старт

Вариант 1 — просто открыть файл:

```bash
index.html
```

Двойной клик по `index.html` в проводнике. Работает, но для стабильной работы прокси лучше локальный сервер.

Вариант 2 — локальный сервер (рекомендуется):

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

Затем открыть в браузере:

```
http://localhost:8000/
```

> Примечание: в режиме `file://` и на простом `http.server` запросы к `/api/admission-list` будут работать только если настроен прокси (см. раздел «Деплой»). Для локальной проверки без деплоя можно временно обращаться к API напрямую, но браузер может заблокировать запрос из-за CORS.

## Как пользоваться

1. В поле «Код и название направления» введите направление, например:
   - `09.03.04 Программная инженерия`
   - `09.03.01 Информатика и вычислительная техника`
2. В поле «Код абитуриента» введите свой уникальный код (например `1124227`).
   Узнать код можно на сайте ДВФУ: «Узнать свой уникальный код абитуриента» — https://www.dvfu.ru/admission/spd/
3. Выберите форму обучения (`Очная` / `Заочная` / `Очно-заочная`), финансирование (`Бюджет` / `Договор`), кампанию и сортировку.
4. При необходимости включите «Только с ВПП (высший приоритет)».
5. Нажмите «Проверить позицию».

Результат:

- карточка направления + мета (кампания, финансирование, дата формирования списка);
- баннер «Вы найдены в списке» или «не найден»;
- метрики: позиция, баллы, приоритет, ВПП;
- строка «Вы в зоне зачисления» / «Вы за пределами мест конкурса»;
- таблица всего списка с вашей подсвеченной строкой.

Поиск по коду нечувствителен к лишним пробелам: `normalizeId()` убирает пробелы перед сравнением.

## Источник данных и API

Базовый адрес API ДВФУ:

```
https://www.dvfu.ru/admission/spd/api/admission-list
```

Приложение формирует query-параметры (`buildQueryParams()` в `index.html`):

| Параметр | Пример / значение | Описание |
| :--- | :--- | :--- |
| `campaignType` | `БВО / бакалавриат / специалитет` | Тип кампании |
| `financingSource` | `Бюджет` / `Договор` | Источник финансирования |
| `studyForm` | `Очная` / `Заочная` / `Очно-заочная` | Форма обучения |
| `trainingDirection` | `09.03.04 Программная инженерия` | Код и название направления |
| `sort` | `BySum` / `ByPriority` | Сортировка |
| `topPriority` | `true` / `false` | Только с высшим приоритетом |
| `atestOrig` | `false` | Фильтр оригиналов (зарезервировано) |
| `enrolled` | `false` | Зачисленные |
| `highPriorityNoOriginal` | `false` | Высокий приоритет без оригинала |
| `approval` | `false` | Согласия |
| `excludeBudgetEnrolled` | `false` | Исключить зачисленных на бюджет |
| `contract` | `false` | Договор |

Прямые запросы из браузера к `dvfu.ru` могут блокироваться CORS. Поэтому в проекте есть серверный прокси для Cloudflare Pages — `functions/api/admission-list.js`. Фронтенд всегда ходит в относительный `/api/admission-list?...`, а функция допроксировывает запрос на `dvfu.ru` с корректным `User-Agent`, отдаёт JSON и кэширует ответ на 300 секунд (`s-maxage=300`). Таймаут на клиенте — 30 секунд, на прокси — 25 секунд.

## Структура проекта

```
fefu-checker-main/
├── index.html                  # Всё приложение: HTML + CSS + JS
├── functions/
│   └── api/
│       └── admission-list.js   # Прокси для Cloudflare Pages Functions
└── README.md
```

Логика в `index.html` разбита на понятные функции:

- `fetchAdmissionList()` — запрос к `/api` с `AbortController`
- `flattenRows()` — разворачивание `sections -> groups -> rows` в плоский список
- `findApplicant()` — поиск по нормализованному коду
- `renderResults()` — карточка статуса, метрики, зона зачисления, квоты
- `renderTable()` — общая таблица, подсветка, скролл к своей строке
- `saveToLocalStorage()` / `loadFromLocalStorage()` — сохранение настроек (`fefuChecker.settings`)
- `showLoading()` / `showError()` / `showEmpty()` — состояния UI

## Деплой на Cloudflare Pages

Проект рассчитан на Cloudflare Pages (статика + Functions):

1. Залейте репозиторий на GitHub.
2. В Cloudflare Pages создайте проект из этого репозитория.
3. Настройки сборки не нужны: Build command — пусто, Output directory — `/` (корень, где лежит `index.html`).
4. Функция `functions/api/admission-list.js` подхватится автоматически, эндпоинт будет доступен как `/api/admission-list`.
5. Откройте выданный домен `*.pages.dev` — приложение готово.

Отдельный бэкенд поднимать не нужно.

## Технологии

- Vanilla HTML + CSS + JavaScript (ES6+), без фреймворков
- Без сборки: `live-server`, `python -m http.server`, `npx serve` или Cloudflare Pages
- Cloudflare Pages Functions для проксирования API
- `localStorage` для сохранения настроек

## Ограничения и дисклеймер

- Это неофициальный инструмент. Данные берутся с публичного API ДВФУ (`www.dvfu.ru/admission/spd`).
- Списки обновляются приёмной комиссией с задержкой. Всегда сверяйтесь с официальным сайтом ДВФУ.
- Автор не гарантирует совпадение позиции с итоговым приказом о зачислении.
